# Session Summary: Streamlit Query Analysis Tool

**Date:** November 30, 2025
**Project:** 606 Query Analysis and Evaluation Tool

## Overview

Created a comprehensive Streamlit web application for analyzing and evaluating the 606 natural language query generation system. The tool enables users to test queries, inspect the decision-making process, review results, and provide structured feedback for continuous improvement.

---

## What We Built

### 1. Main Streamlit Application (`streamlit_app.py`)

A full-featured web application with the following components:

#### Input System
- **Dual Input Modes:**
  - Manual text entry for ad-hoc natural language questions
  - Dropdown selector to choose from test questions in `eval/nl_sql_pairs_additional.jsonl`
- **JSONL Integration:** Reads test questions with metadata (ID, table hints, notes)
- **Robust Path Resolution:** Handles multiple possible file locations with detailed error reporting

#### Query Analysis Interface
- **Tabbed Display for SQL Queries:**
  - **Tab 1 - SQL Query:** Syntax-highlighted SQL code generated by the system
  - **Tab 2 - Logic Details:** Comprehensive breakdown showing:
    - Classification tags (what keywords were detected)
    - Triggered keywords and patterns
    - Table selection logic
    - Query intent (operation, metric, dimensions)
    - Heuristics and calculations used
    - Query type routing information

#### Results Display
- **SQL Results Section:**
  - Formatted DataFrame display of query results
  - Row count metrics
  - CSV download functionality with timestamped filenames
  - Handles empty results gracefully

#### GenAI Response Section
- Displays natural language narrative responses
- Shows how the AI synthesizes and explains query results
- Handles both single-query and complex multi-table responses

#### Feedback System
- **Query Notes:** Text area for documenting SQL query issues (mistakes, improvements, incorrect logic)
- **GenAI Notes:** Text area for commenting on AI response quality (accuracy, clarity, completeness)
- **Overall Rating:** 1-5 star slider for rating the complete query generation process
- **Save Functionality:** Persists all feedback to CSV with timestamp

#### Analytics Dashboard (Sidebar)
- Real-time metrics:
  - Total feedback entries count
  - Average rating across all queries
- Download all feedback as CSV
- API configuration display
- About section with feature documentation

#### Data Storage
- Automated CSV storage (`query_feedback.csv`) capturing:
  - Timestamp
  - Original question
  - Generated SQL query
  - Query type/routing path
  - SQL results count
  - GenAI narrative response
  - User notes (query and GenAI)
  - Overall rating

## Technical Integration Points

### API Integration
- Connects to FastAPI backend at `/ask` endpoint
- Handles POST requests with JSON payload
- 30-second timeout for long-running queries
- Robust error handling with user-friendly messages

### File System Integration
- Reads from `eval/nl_sql_pairs_additional.jsonl`
- Writes to `query_feedback.csv`
- Handles relative and absolute paths
- Creates CSV with headers on first write

### Data Flow
```
User Input (Streamlit)
    ↓
HTTP POST → FastAPI Backend
    ↓
Query Classification & Routing
    ├→ Planner (template-based)
    ├→ Direct handlers
    └→ Complex multi-table
    ↓
PostgreSQL Database
    ↓
Results + Metadata
    ↓
Streamlit Display (3 sections)
    ↓
User Feedback
    ↓
CSV Storage
```

## Usage Workflow

1. **Start Backend:** `uvicorn main:app --reload --port 8000`
2. **Launch Streamlit:** `streamlit run streamlit_app.py`
3. **Select Input Mode:** Manual or Test Questions
4. **Enter/Select Question:** Type or choose from dropdown
5. **Generate Query:** Click button to send to API
6. **Review Results:** Check SQL, logic, results, and AI response
7. **Provide Feedback:** Add notes and rating
8. **Save:** Click save to persist feedback to CSV
9. **Analyze:** View metrics in sidebar, download feedback data
